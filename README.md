# CIRA 设备端 Web 交互原型

> 把 360×360 圆形屏幕里的光生命体，在桌面浏览器里 1:1 模拟出来。

> 📦 **要给开发？** 先看 **[HANDOFF.md](./HANDOFF.md)** —— 这是设计原型 → 嵌入式开发的移交规格书（状态机、交互链路、星云视觉引擎移植参数、与底层模型的数据契约、流程图）。Web 原型仅作交互参考，不可直接刷设备。

## 怎么打开

### 方式 1: 直接双击 `index.html`
浏览器里直接打开即可（无需服务器）。但部分浏览器对 `file://` 下的 Canvas 有限制，**推荐方式 2**。

### 方式 2: 起一个本地 server（推荐）
```bash
cd cira-prototype
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 已经实现的功能

### 圆屏主视觉 (光生命体 · Engine v0.3 "Nebula")

v0.1 "扁平"、v0.2 "体积雾"、v0.21 "星尘" 之后，v0.3 目标是**星云 (Nebula)** 质感——
朦胧不再靠"大而糊的光斑"，而是靠**海量极小锐利星点的疏密渐变**（密核 → 稀边）营造。

在 v0.2 体积粒子光场基础上的星云化改动：

| # | 改动 | 效果 |
|---|------|------|
| A | Sprite 亮核收到 0.10、0.66 处几近熄灭 | 每颗从"软光斑"变"锐星点" |
| B | 粒子 ~460 → ~1300（4 层，最小尺寸减半，新增稀疏外场） | 靠数量+疏密表达朦胧，不靠单颗糊 |
| C | 渲染直径 5.2 → 3.1、最小 2.6 → 1.3，分层 alpha 收紧 | 点更小更细，密处成雾、疏处见星 |
| D | 中心雾核 3 → 2 层，半径/透明度下调，内核 0.40 → 0.30 | 中心不再"结块"，更通透 |

原 v0.2 的体积粒子光场底座（下列）保留：

| # | 技术 | 解决的问题 |
|---|------|-----------|
| 1 | **3D 球面分布 + 透视投影** (Fibonacci 采样) | 粒子有前后景深，近大近亮、远小远暗 → 有体积 |
| 2 | **加色混合** `globalCompositeOperation='lighter'` | 粒子重叠处自然变亮，这才是"光"而不是不透明贴纸 |
| 3 | **运动拖尾层** (离屏 canvas 每帧只擦 ~14%) | 粒子留下光轨 → "飘渺""流动" |
| 4 | **FBM 噪声场驱动形变** | 轮廓永远不规则、有机呼吸，不是完美圆 |
| 5 | **中心空腔 + 多层雾核** | 去掉硬边实心圆，光从内部透出，中心亮度带噪声起伏 |
| 6 | **三层粒子 + 色散** | 核心尘 84 / 主体云 122 / 游离星尘 48；70% 主色 + 18% 暖橙 + 12% 软粉 |
| 7 | **Sprite 预渲染 + drawImage** | 254 颗粒子稳定 60fps（每帧 createRadialGradient 会卡） |

其它：
- **6 种状态 × 7 种情绪** 的视觉差异（形态参数平滑插值，切换是"化"过去不是"跳"过去）
- **声波动环**（listening 时随音频脉动，画进拖尾层所以环也有残影）
- **唤醒脉冲** / **暗角 vignette**（增强体积错觉）
- 全暖色系，物理上不可能出现绿色

**调参入口**（右侧调试面板 → 光生命体·视觉调参）：
- 粒子密度滑杆 40%–180%（越高越"雾"，越低越"星”）
- `✦ 触发脉冲` / `◎ 唤醒爆发`

DevTools 里也可以直接调：
```js
__cira.lf.setDensity(1.6)      // 更浓密
__cira.lf.setState('thinking') // 漩涡形态
__cira.lf.pulse()
```

### 状态机 (与 PRD §7 四态 + Settings 浮层对齐)
| 状态 | 触发 | 视觉 |
|------|------|------|
| Idle | 默认 / 唤醒前 | 核心光白核, 缓慢呼吸 |
| Listening | 点按屏幕 / 点 "开始对话" | 暖橙, 粒子扩散 + 声波环 |
| Thinking | ASR + LLM 生成中 | 紫, 粒子内收循环 |
| Speaking | TTS 播放中 | 暖橙/软粉(随情绪), 光团波动 + 字幕 |
| Settings | 长按 1.2s | 半透明圆形浮层 |
| Offline | 模拟断网 | 白弱化, 形态下沉 + 离线 banner |

### 触摸交互
- **点按屏幕** → 唤醒进入 Listening（接收字幕逐字"识别"出现）
- **长按 1.2s** → 进入 Settings（多视图导航）
- **拖动滑杆** → 调音量 / 屏幕亮度
- 菜单条目 `›` 逐级进入，左上 `‹` 逐级返回

### Settings · 多视图导航 (圆屏内, v0.3)

主菜单 5 项，每项都是独立可下钻的子页面，模拟真机设置的完整交互链路：

| 菜单 | 交互链路 |
|------|----------|
| **Wi-Fi** | 开关 → 自动搜索(spinner) → 网络列表(信号/锁标) → 点击连接：已保存/开放直连、加密走**屏内键盘输密码**(含 ⇧ 大小写 / ⌫ / 👁 明文) → 已连接项进详情 → **忘掉此网络** / 重新搜索 |
| **蓝牙** | 开关 → 扫描 → 我的设备 / 可用设备两栏 → 点可用设备**配对连接**(configuring→已连接) → 进设备详情 → **忽略此设备** / 重新扫描 |
| **音量** | 大数字 + 滑杆(0–100)，与右侧调试面板全局音量双向同步 |
| **屏幕亮度** | 滑杆 **1 nit(夜间) – 400 nit(日光)**，默认 200 nit；实时黑色遮罩：200–400 保持通透、<200 逐渐变暗模拟夜间 |
| **模式** | 正常 / 安静 / 故事 三选一（✓ 标记）|

> 亮度行业参考：儿童陪伴设备夜间可低至 ~1 nit（避免刺眼），室内正常 150–250 nit，强光环境上限约 400 nit。
> 每项当前值实时回显在主菜单右侧（如 Wi-Fi "CIRA_Home"、亮度 "200 nit"）。

### 主界面字幕版心约束 (v0.3)
- 接收(Listening)与输出(Speaking)都有字幕，且**视觉区分**（接收态更暗 + 前缀语气）
- 字幕严格限制在 **208px 版心 · 13px · 最多 3 行**，超出省略，永不撑破圆屏

### 异常态 (§8)
- **断网** → worried 颜色 + 离线 banner
- **恢复** → 回 idle

### 控制面板 (右侧, 调试用)
- 一键切换 6 个状态
- 覆盖情绪 (calm/curious/happy/thinking/comfort/worried)
- 自定义字幕 + 触发模拟对话
- 全局音量滑杆
- 异常态按钮

## 设计语言对齐

| 维度 | 已对齐 |
|------|--------|
| 配色 | 暖橙 `#FF8A3D` / 软粉 `#FF9EB5` / 紫 `#A98CE0` / 暖白 `#FFE9C7` / 黑 `#000000` |
| 主体 | 光生命体 (粒子光团, 非脸, 非具象种子) |
| 动效 | 有机运动 (呼吸 / 漂浮 / 聚合 / 扩散 / 波动), 禁快闪、禁旋转扫描 |
| 圆屏约束 | 360×360, 安全区半径 ≤150, 圆形裁切 |
| 状态数 | 四态 (Idle/Listening/Thinking/Speaking) + Settings 浮层 + Offline |
| 唤醒 | 点按屏幕, 长按 1.2s 进 Settings |

> **注**：核心光使用"暖白" `#FFE9C7` 而非纯白 `#FFFFFF`，避免 Mac 屏幕色温/Night Shift 模式/子像素渲染把白光推成偏绿。所有状态都保持暖色调底，画面永远不会出现绿色。

## 不做的事

- **不接真实 LLM** — 这只是视觉/交互原型, 不接服务端
- **不模拟硬件触摸** — 用鼠标/触屏 pointerdown/pointerup
- **不做 A11y 完整测试** — 圆屏 UI 不依赖键盘导航
