# CIRA 星云交互 v1.0 定稿规格（Nebula Interaction v1.0）

> **版本**：v1.0 · 定稿于 2026-08-12
> **源文件**：`android-proto/cira-android.html`（场景编排 + 触碰/唤醒）+ `android-proto/lifeform.js`（光生命体渲染引擎）
> **定位**：安卓 App（小米15）主界面星云 + 待机悬浮生命体的**交互与动效定稿**。模型未接入，仅视觉/触感/流转手感定版。
> **配套**：模型接入契约见 `docs/CIRA_APP_INTEGRATION_REQUIREMENTS.md`（§4 定义 emotion/ignite 归 Core、status 归 App）。

---

## 1. 视觉基调（不可改，除非重做整套调色）

- **暖色体积光场**，绝不用青/蓝/绿冷色。主色：
  - 暖橙 `#FF8A3D` · 软粉 `#FF9EB5` · 紫 `#A98CE0` · 暖白核
  - 核心星团偏暖白，外缘偏橙/粉，思考态微染紫。
- **粒子结构**：3D 球面三层（核心尘 / 主体星云 / 游离星尘）+ 中心聚集小星群（层4，约 340 颗，半径 0.006~0.055，紧致旋转成明亮核心）。密度：安卓 `density=1.45`、悬浮小窗 `1.25`（相对引擎基准）。
- **质感要素**：加色辉光（additive glow）+ 运动拖尾光轨 + FBM 噪声"有机呼吸" + 自转 3D 景深 + 暖暗角聚焦中心。
- **中心小星群是独立引力场**：触碰时被吸引系数最低（见 §2 layerDamp），几乎不被吸走。

## 2. 触碰交互 —— "被吸引汇聚"（核心手感，本版最大亮点）

**模型**：万有引力式速度积分（非位移缓动）。每颗粒子带速度 `vx,vy`，引力**加速度** `a = G/(d+soft)` 朝指尖绝对点。

**参数（lifeform.js，全部相对 `base=min(屏宽,屏高)`）：**
| 参数 | 值 | 含义 / 可调方向 |
|---|---|---|
| `G` | `base * 30` | 引力总强度；越大整体越猛 |
| `soft` | `base * 0.04` | 软化半径，防 `d→0` 奇点爆冲 |
| `Rmax` | `base * 0.45` | **最大影响半径**：圈外星完全不受力，手指扫到才动；想圈更小→`0.32~0.38`，更大→`0.55` |
| `coreR` | `base * 0.028` | 汇聚成的"点"半径（不大，无中空环） |
| `layerDamp` | 层4=0.05 / 层0=0.72 / 其他=1.0 | 中心星群最难吸、外散星最易吸 |
| 旋吸 `sw` | `a*0.12*min(1, d/(base*0.12))` | 切向旋吸，近点归零、远处才把星卷进去 |
| 吸引阻尼 | `exp(-dt*2.0)` | 限位稳定 |
| 松手阻尼 | `exp(-dt*1.4)` | 回轨道时更顺 |
| 回复弹簧 | `3.2` | 松手后偏移回原轨道；想更利落→`4~5`，更慢→`2.2` |
| `vmax` | `base * 3.0` | 速度限幅防极端 |
| `attract` 上升 | aRate `5.0`（按下→1） | 手指一碰引力快速建立，手感明显 |
| `attract` 松手 | `clearAttractor()` **当帧归零** | 手指一离开引力立刻消失，星靠弹簧缓缓散回 |

**行为语义（用户验收通过）：**
- 点一下 → 近处星先被吸、**越近越快加速冲入**（远小近大，类万有引力），远处随自转转到附近才逐渐加入。
- 手指移动 → 引力点实时跟随，整团跟手不散。
- 长按 → 持续汇聚成"另一个星群"（手指处明显聚出一团）。
- 松手 → 引力**当帧消失**，星靠弹簧缓慢飘回原轨道（环绕中心星群），宇宙复原。
- 圈外（`d>Rmax`）星初始不动，只有手指移动扫到才被卷入。

> 演进教训（已验证）：① 不可用硬半径 cutoff（进圈即死、过程停滞）→ 用无硬边界软化井；② 不可让"到点"=目标位移归零（星会飘走）→ 目标必须是**绝对点钉死**；③ 不可匀速缓动（远近同速）→ 必须加速度积分实现"远慢近快"。

## 3. 状态动效（STATE_PROFILE，与引力同源的"动效词汇"）

基调不变，各状态用同一套语言（呼吸/旋转/收束/声波）表达不同意图，构成一个系列。

| 状态 | breath | spread | coreGlow | swirl | flow | ripple | morph | 动效语义 |
|---|---|---|---|---|---|---|---|---|
| **idle 待机** | .046 | 1.00 | .58 | .060 | .48 | 0 | sphere | 静息呼吸，正常铺开 |
| **listening 聆听** | .064 | 1.12 | .74 | .18 | .72 | .85 | listen | 开放接收：微张 + 声波环轻涌 + 随声音张合 |
| **thinking 思考** | .026 | .84 | .94 | .60 | 1.00 | 0 | vortex | 屏息收紧 + 向内卷漩涡（外圈转更快，**呼应引力收拢感**） |
| **speaking 回应** | .082 | 1.12 | .80 | .13 | .72 | .70 | speak | 向外辐射波（内层先动、沿半径向外传）+ 较强声波环 |
| **offline 休眠** | .030 | .78 | .20 | .018 | .20 | 0 | droop | 暗、垂、近静止（sag 22） |
| **wake 唤醒** | .104 | 1.34 | .98 | .34 | 1.15 | 0 | burst | 从一点炸开，最亮最活 |

- `morph` 分支：`sphere`=静息球；`listen`=开放接收+声波环；`vortex`=向内卷漩涡；`speak`=向外辐射波；`droop`=暗垂；`burst`=炸开。
- 切换用 `setEmotion`/`setState` 平滑 lerp，不跳变。

## 4. 唤醒 + VAD 聆听流转（场景B 原型）

- **VAD（能量阈值法模拟，非真引擎）**：`AnalyserNode` 算 RMS，`VAD_THRESHOLD=0.06` 判人声。
- `SILENCE_MS=1800`：句尾静默判定（说完后静默 1.8s = 一句说完）。
- `INIT_SILENCE=6000`：初始静默超时（唤醒后一直无人开口才退出悬浮）。
- **流转**：唤醒 → 回放 `wake_src/ai.m4a`(哎) 或 `wo.mp3`(我在) → `listen`（开麦/VAD）；有人声→收录中；静默 1.8s→`think`(1s)→`speak`(1.8s，本地占位文案)→回 `listen`；一直无人→6s 超时退出。
- 进度条 = "剩余静默预算"（说话涨满、停说回落、没说过了退出），**不再是倒计时**。
- **降级**：局域网 `http://` 非安全上下文，`getUserMedia` 拿不到权限 → 自动切悬浮窗内「按住说话」按钮（按住=有声音、松=静默），照样验流转。
- 唤醒检测（Porcupine 离线）在**原生层**，本原型用「模拟唤醒」按钮代替。

## 5. 接入真模型后的职责边界（引用 `docs/CIRA_APP_INTEGRATION_REQUIREMENTS.md` §4）

- **`emotion`（9 值）+ `ignite`** 归 **Core**：随 `/v1/respond` 的 `display_state` 返回，是回复内容属性，App 据此驱动**配色与点亮**——唯一权威来源，App 不再自编情绪。
- **`status`（listening/thinking/speaking/wake/idle）** 归 **App**：是调用生命周期的副产品（VAD 命中→listening，发 respond→thinking，收到→speaking，原生唤醒→wake，空闲→idle）。Core 不参与 listening/thinking，故不在 Core 侧。
- 因此本原型里 `REPLY_PHRASES` 占位文案、硬编码状态，接模型后即废，由桥的真实 `display_state` 替代。

---

## 6. 已知边界（封装前须知）

- 场景A（全屏星云 App）+ 场景B（待机悬浮生命体）视觉/触感/流转已定版，但**均未接真模型**。
- 场景B 的"真唤醒词 + 系统级悬浮窗 + 后台常驻收音"**必须 Capacitor 原生模块**（前台 Service + `SYSTEM_ALERT_WINDOW` + Porcupine/Vosk + Silero VAD），HTML 仅原型其视觉与流转手感。
- 局域网 `http://` 下麦克风受限，真机验麦需 https 隧道或 Capacitor WebView（安全上下文）。
